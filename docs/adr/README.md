# Architecture Decision Records (ADR)

Un ADR registra **una decisión** que afecta a más de un módulo o app: el contexto, lo que se decidió y sus consecuencias. No se editan: si una decisión cambia, se crea un ADR nuevo que **reemplaza** al anterior.
