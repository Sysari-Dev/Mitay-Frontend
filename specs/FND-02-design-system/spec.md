## Objetivo

Identidad visual común: tokens de color, temas claro/oscuro, tipografía y primeros componentes.

## Criterios de aceptación

- [x] Paleta "Rocoto + Chicha" con tokens completos en claro y oscuro; paleta de Tailwind desactivada
- [x] Tema claro por defecto, `themeScript` sin parpadeo, `ThemeToggle`, `ThemePreview`
- [x] Tipografía Nunito (títulos), Figtree (texto), Geist Mono centralizada en `@mitay/ui/lib/fonts`
- [x] Átomos `button` y `badge` con variantes `primary/secondary/tertiary/destructive`
- [x] Vistas de baja fidelidad en las tres apps
